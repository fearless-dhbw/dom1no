# dom1no — Detailed Use Cases

This folder documents **one user goal per use case**, using a RUP-inspired structure with actors, trigger, preconditions, normal flow, extensions, postconditions, and links to SRS requirements.

- [DUC-01 — Play a Domino Match](DUC-01-play-domino-match.md)
- [DUC-02 — Send a Friend Request](DUC-02-send-friend-request.md)

The numbering `DUC-*` is intentionally different from the SRS appendix's `UC-*` diagram IDs. The latter are categories of overview diagrams, **not** the IDs for the detailed use-case specifications.

The existing team overview diagrams are kept in [`../diagrams/`](../diagrams/), and UI snapshots are kept in [`../mockups/`](../mockups/). Editable designs: [Figma](https://www.figma.com/design/kJDrWOX1E7Uci3U2Gp9Cvs/Untitled?node-id=0-1&t=MYacNVOjFRvgLBVh-1).

**Team review required:** Confirm the specific domino Rules Profile (`RP-01`), gameplay recovery rules (`DEC-06`), and friend request/privacy edge cases (`DEC-09`) before baselining and acceptance testing.
